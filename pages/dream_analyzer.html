Dream Analyzer

Summer 2026 - Present

Project Description

Dream Analyzer is a local Python pipeline for parsing a dream journal, embedding dreams with Ollama, storing them in ChromaDB, and asking retrieval-augmented questions. The goal is to analyze a private dream journal over time while keeping all raw journal data local.

The project is designed to support semantic dream retrieval, theme extraction, longitudinal analysis, graphing, and eventually a CLI or GUI interface where a user can ask natural-language questions about their dream journal. It is currently a work in progress.

Workflow

The pipeline parses plain-text journal entries grouped by date, supports optional tag lines, and exports structured dream records. Those records can then be embedded into a ChromaDB index for semantic search and retrieval-augmented generation using locally running Ollama models.

Current Tools

  • Retrieve similar dreams with semantic search.
  • Plot tag frequency over time.
  • Cluster dream embeddings and generate theme evidence, static plots, an interactive map, and per-dream assignments.
  • Compute summary statistics for the journal.
  • Analyze a single dream, optionally with related dreams for context.
  • Extract structured features and build a character lookup from dream records.
  • Ask retrieval-augmented questions with a basic RAG script or a tool-capable dream agent.
  • Compare chat and embedding model combinations and evaluate retrieval quality.
